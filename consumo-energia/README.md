# ⚡ Consumo de Energia

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)

Este projeto calcula o consumo mensal de um aparelho elétrico e seu custo aproximado.

## Como funciona

O programa pede:

- Nome do aparelho;
- Potência em watts;
- Horas de uso por dia.

A fórmula usada é:

```text
consumo = (potência × horas por dia × 30) ÷ 1000
```

O custo é calculado usando a tarifa de **R$ 0,75 por kWh**.

## Como executar

No terminal, dentro da pasta do projeto, execute:

```bash
python app.py
```

Projeto feito em Python. 🐍⚡
