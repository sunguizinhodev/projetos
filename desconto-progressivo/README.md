# Desconto Progressivo

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)

Programa em Python que calcula um desconto de acordo com o valor total da compra.

## Regras

| Valor da compra          | Desconto |
| ------------------------ | -------: |
| Menor que R$ 200,00      |       5% |
| De R$ 200,00 a R$ 299,99 |      10% |
| A partir de R$ 300,00    |      15% |

## Como executar

No terminal, dentro da pasta do projeto:

```bash
python main.py
```

Digite o valor da compra quando solicitado.

## Exemplo

```text
Valor total da compra: R$300
Desconto aplicado: R$45.00
Valor total a pagar: R$255.00
```
